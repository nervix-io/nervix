# Typed states qualification map

This map follows semantic states from construction through execution and reporting.
Historical run results and audit findings are retained on [Typed States 10](https://app.clickup.com/t/86bc2gn70).
The [typed states architecture](../docs/src/typed-states.md) owns the current modeling rules.

| Contract | Executable evidence |
| --- | --- |
| Typed expression scopes and message-error operations | [Frontend](../crates/nervix-vm/src/frontend.rs), [message-error Model](../crates/models/src/message_error.rs) and [runtime operation tests](../src/runtime/filter_map/tests/typed_operation_tests.rs) carry scope availability and `MessageErrorOperation` as types. [Branch namespaces](features/runtime/branch_namespace.feature), [expression semantics](features/runtime/expression_function_semantics.feature) and [error policies](features/runtime/node_error_policies.feature) exercise valid scopes, unavailable scopes and structured route operations. |
| Exact branch and domain identity | [ResolvedBranching](../crates/models/src/statement.rs) carries either unbranched state or the named branch with its fields and sensitivity. [Graph projection](../src/registry/graph.rs) does not invent a domain. [Explicit branches](features/runtime/explicit_branch.feature) distinguish equal key shapes with different names; [materialized state](features/runtime/materialized_stream.feature) checks root reporting locally and remotely and interleaved concrete branches; [branched subscriptions](features/runtime/branched_subscription.feature) check sensitivity. |
| Required schema identity and explicit schema-independent state | [SchemaFingerprint](../crates/models/src/schema_fingerprint.rs) is required for schema-bound scheduled nodes, while [runtime state identity](../src/runtime/state_store.rs) explicitly distinguishes schema-independent state. [Materialized state schema change](features/runtime/relay_materialized_state_alter.feature) and owning state-store tests cover recreation, restart and stale state rejection. |
| Optional applied and snapshot progress | [Schedule application](../src/runtime/schedule_apply.rs) stores an optional applied revision under its existing mutex and tests zero, equal, stale, maximum and failed application. [Retention](../crates/consensus/src/retention.rs) distinguishes no request, a request before any completed snapshot and completed index zero. [Narrow activation](features/cluster/narrow_schedule_activation.feature) and [consensus storage](features/cluster/consensus_storage.feature) exercise the public recovery boundaries. |
| Typed ACK handoff transitions | [AckHandoffState](../src/runtime_ack.rs) exposes tracking and completion while its owner alone encodes them in one atomic word. The same file tests active attachment, final ACK, `REQUIRED WAIT`, and domain/ingestor tracker conservation under Shuttle; [materialized state](features/runtime/materialized_stream.feature) and [narrow activation](features/cluster/narrow_schedule_activation.feature) cross the public waiting and handoff paths. |
| Typed endpoint availability | [NodeEndpoint](../crates/models/src/node_endpoint.rs), [gossip publication](../src/cluster.rs), [consensus admission](../crates/consensus/src/lib.rs) and [peer targets](../crates/interconnect/src/peer_target.rs) retain endpoint availability. Unit tests cover field-by-field publication, malformed or replaced endpoints and absent interconnect admission. [Bootstrap](features/cluster/bootstrap.feature), [rejoin](features/cluster/rejoin.feature), [leader failover](features/cluster/leader_failover.feature) and [session redirect](features/runtime/session_protocol.feature) exercise observable transitions. |
| Typed BSON conversion failure | [MongoDB conversion](../crates/connectors/mongodb/src/collection/mod.rs) produces a typed record failure without publishing the document; its tests cover top-level and nested unsigned values. [MongoDB emission](features/runtime/mongodb_emission.feature) checks ordinary fields, conflict keys, genuine null and mixed valid records on one and three nodes. |
| Checked VM counts and timestamp range | [Count values](../crates/nervix-vm/src/count.rs) preserve integer signedness and extremes; [VM execution](../crates/nervix-vm/src/runtime.rs) reports unsupported output and pre-epoch UUID time as row errors. [Expression semantics](features/runtime/expression_function_semantics.feature) checks full unsigned counts and output bounds; [domain clock](features/runtime/domain_clock_contract.feature) checks epoch and pre-epoch UUID time. |
| Typed session metadata and outcomes | [Upload outcome](../src/application/session/upload.rs) retains an optional nonzero assigned version; [wire diagnostics](../crates/client-wire/src/common.rs) retain optional spans, including a span starting at zero; [console dispatch](../crates/web-console/src/main.rs) uses typed command purpose and outcome. [Wire tests](../crates/client-wire/src/tests/replies.rs), [client tests](../crates/client-core/src/tests.rs), [session protocol](features/runtime/session_protocol.feature) and [console REPL](features/web-console/plexus_repl.feature) cover absent and present metadata, typed redirects and domain selection. |
